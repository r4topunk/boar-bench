# Reference answers: public re-issue

`refs.jsonl` holds the 60 frozen reference answers of bench v0.1 (frontier model with web search, prompt `prompts/reference.v1.md`, sha256 `d51443438dfebcc7d2c3a0136340c70a68f495e1214c00a3a8c56bcdbc755972`).

- Generated by Claude Opus (`claude-opus-5-5`) through Claude Code with the WebSearch and WebFetch tools, 2026-09-30 to 2026-10-02. Each row records model, CLI version, prompt sha, timestamps, searched queries and cited source URLs. Answers may quote their cited sources.
- Private file (internal build): sha256 `bd235bb9811f6d1ae88ba2d2ae3973e3572d75b6c451ee4cdd3a2e7644db48b1`.
- Public file v1 (first public release, 2026-10-15): sha256 `689c6f0457db26f6210e61338e38bca70e002625672daf673234576f57ab45b3`.
- Public file v2 (this one, v1.0 full open record, 2026-10-26): sha256 `4a7da939ed84a953ceb852d237d96015f09df651c98c5a5aedb64daf63224fdc`.
- Changes against the private file: the `promptFile` field (a local filesystem path, present in every row) was removed; in v2 the per-call price fields (`listPriceEquivalentUsd`, `costBasis`) were also dropped and the `via` label reads `claude-code (claude -p, cleanEnv: no API key)`. The `answer` text of every row is byte-identical to the private file, and every other remaining field is unchanged. `refs/MANIFEST.json` pins the public sha, and `harness/judge.mjs` checks it before judging.
- Numbers computed against the private file are valid for this file: the judge reads `answer` only.
